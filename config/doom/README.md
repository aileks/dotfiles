# Doom Emacs Config

My personal [Doom Emacs](https://github.com/doomemacs/doomemacs) configuration.

## Install

```sh
git clone https://github.com/aileks/doom ~/.config/doom
doom sync
```

## Custom Keybinds

| Key | Action |
| --- | --- |
| `jk` | Escape |
| `SPC f t` | Search project TODO comments |
| `SPC p t` | Project task menu |
